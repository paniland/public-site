Privacy policy

This policy describes how Paniland Assistant's current Google Workspace connection handles Google user data for its authorized user, Peter Petrov.

Data accessed

The integration accesses only data covered by scopes Peter grants through Google OAuth:

  • Gmail message content and metadata for reading mail and creating drafts.
  • Google Drive file content and metadata for reading files and managing files granted to the application.
  • Google Calendar lists, settings, and events for reading schedules and managing events on calendars Peter owns.
  • Basic Google identity information needed to identify the authorized account.

Use of data

Google user data is used only to answer Peter's explicit requests and perform the Workspace action he requested. It is not used for advertising, profiling, sale, or access by unrelated users.

Storage and processing

OAuth refresh credentials are encrypted and stored separately on each Peter-controlled workstation. Google user data is not stored in a public Paniland service. Content used in an assistant interaction can appear in local agent session history and Peter-controlled private backups or search indexes.

When necessary to answer a request, relevant content can be transmitted to the AI model provider Peter selected for that agent session. Provider processing and retention are governed by Peter's agreement with that provider.

Sharing

Paniland does not sell Google user data. Data is disclosed only to service providers needed to execute Peter's request, such as the selected AI model provider and Google itself, or when required by law.

Retention and deletion

Workspace data returned during a request can remain in local session history and Peter-controlled backups until Peter deletes those records under his normal retention practices. Revoking OAuth access prevents future API access but does not automatically erase existing session records.

Control and revocation

Peter can revoke the workstation credential locally with gws-workstation-auth logout and can revoke the application's Google access from Google Account connections.

Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions about this policy can be sent to peter@petrovs.io.
