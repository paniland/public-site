Paniland Assistant

Paniland Assistant lets authorized members of the Paniland household ask their AI assistants to work with connected services. It is not offered to the public and has no public application backend.

Current Google Workspace access

  • Read Gmail messages and create email drafts.
  • Read Google Drive files and manage files granted to the application.
  • Read calendars and manage events on calendars Peter owns.

The integration does not request unrestricted Gmail deletion, unrestricted Drive management, or Google Workspace administrator access.

How it operates

OAuth credentials are stored on Peter-controlled workstations. Requests originate from local agent sessions, and Google Workspace content is accessed only when Peter asks an assistant to perform a related task. Other deployments use separate credentials and are documented before they are enabled.
